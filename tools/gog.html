gog

gog is a personal command-line tool that queries Google services (Gmail only) from the machine of its single user, in read-only mode.

Strictly private use.

Privacy Policy

▾

Data accessed

The emails of the user's Gmail account, via the Gmail API with the gmail.readonly scope (read-only).

Usage

Requests are executed locally from the user's machine. No data is stored on a server, transmitted or shared with any third party.
